# News2Video

**News2Video** — консольное приложение на C#, которое автоматически получает новости из RSS, извлекает текст статьи, создаёт короткое вертикальное видео и загружает его на Яндекс Диск.

## 1. Функция программы

Программа автоматически:

* получает новые новости из RSS 3DNews;
* загружает страницу статьи;
* извлекает заголовок и основной текст;
* очищает текст от рекламы и лишних элементов;
* создаёт видео с фоном, заголовком, текстом и музыкой;
* загружает готовое видео на Яндекс Диск;
* сохраняет обработанные ссылки, чтобы не создавать видео повторно.

## 2. Этапы обработки данных

```text
RSS
 ↓
Получение списка новостей
 ↓
Проверка processed.txt
 ↓
Загрузка HTML статьи
 ↓
Парсинг и очистка текста
 ↓
Подготовка текста
 ↓
Создание видео через FFmpeg
 ↓
Загрузка на Яндекс Диск
 ↓
Сохранение URL как обработанного
```

## 3. Как это работает

После запуска `Program.cs` регулярно проверяет RSS-ленту и получает список последних публикаций. Для каждой новости программа проверяет `processed.txt` — если ссылка уже была обработана, статья пропускается.

Для новой статьи `WebWorker` загружает HTML-страницу. Полученный HTML передаётся в `Parser`, который находит заголовок и основной текст статьи, удаляет рекламу, изображения, комментарии и другие ненужные элементы.

После этого `VideoEditor` подготавливает текст и передаёт его в **FFmpeg**. В качестве основы используется фоновое видео, поверх которого размещаются заголовок и текст новости. Также добавляется фоновая музыка. В результате создаётся вертикальный ролик **1080×1920** длительностью **15 секунд**.

Готовый файл передаётся в `YandexDiskUploader`, который загружает его через **Yandex Disk API**. После успешной загрузки URL статьи записывается в `processed.txt`, поэтому при следующей проверке эта новость повторно не обрабатывается.

## 4. Стек

* **C# / .NET**
* **HttpClient** — HTTP-запросы
* **AngleSharp** — парсинг HTML
* **XDocument** — обработка RSS/XML
* **FFmpeg** — генерация видео
* **Yandex Disk REST API** — загрузка видео
* **File System** — хранение временных и готовых файлов
