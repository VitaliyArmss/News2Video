# News2Video

**News2Video** — консольный скрипт на C#, предназначенный для автоматической обработки новостей. Скрипт получает публикации из RSS, с помощью встроенного парсера извлекает содержимое статьи из HTML, после чего формирует короткое видео и загружает его на Яндекс Диск.

## 1. Функция программы

Основная задача программы — автоматически обрабатывать новые новости без ручного вмешательства.

Скрипт:

* получает новости из RSS 3DNews;
* загружает HTML каждой новой статьи;
* встроенным парсером извлекает заголовок и текст;
* очищает страницу от рекламы, изображений и ненужных элементов;
* передаёт полученные данные в FFmpeg для создания видео;
* загружает готовый ролик на Яндекс Диск;
* запоминает уже обработанные статьи.

## 2. Этапы обработки данных

```text
RSS
 ↓
Получение новых статей
 ↓
Загрузка HTML
 ↓
Встроенный парсер
 ↓
Очистка и извлечение текста
 ↓
Создание видео
 ↓
Загрузка на Яндекс Диск
 ↓
Сохранение обработанной ссылки
```

## 3. Как это работает

После запуска `Program.cs` каждые 5 минут проверяет RSS-ленту и получает список последних публикаций.

Для каждой новой статьи `WebWorker` загружает HTML-код страницы. Затем `Parser` анализирует полученный HTML и самостоятельно определяет, где находятся заголовок и основной текст статьи. Парсер удаляет рекламные блоки, изображения, комментарии, социальные виджеты и другие элементы, которые не относятся к содержанию новости.

Из очищенной страницы формируется текст новости, который затем передаётся в `VideoEditor`. Он использует **FFmpeg** для создания вертикального видео с фоновым роликом, заголовком, текстом статьи и музыкой.

После создания видео `YandexDiskUploader` загружает файл на Яндекс Диск. Ссылка на успешно обработанную статью сохраняется в `data/processed.txt`, поэтому при следующем запуске или проверке RSS она не будет обработана повторно.

Таким образом, основой проекта является **автоматический скрипт с собственным парсером веб-страниц**, а генерация видео и загрузка файла являются следующими этапами обработки полученных данных.

## 4. Стек

* **C# / .NET** — основа скрипта
* **AngleSharp** — встроенный парсер HTML
* **HttpClient** — загрузка RSS и веб-страниц
* **XDocument** — обработка RSS/XML
* **FFmpeg** — создание видео
* **Yandex Disk REST API** — загрузка готовых файлов
* **File System** — хранение HTML, обработанных ссылок и видео
